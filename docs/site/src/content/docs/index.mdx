ecc runs `claude` headless, talks to it over pipes in its stream-json protocol,
and draws the conversation as ordinary Emacs buffer text — no terminal
emulator. Permission requests, diffs and plans are answered with a keystroke,
from the transcript or from whatever buffer you happen to be editing.

Start with the [overview](/emacs-claude-code/start/overview/), then
[install it](/emacs-claude-code/start/installation/). The reference section
lists every command, setting and key.
