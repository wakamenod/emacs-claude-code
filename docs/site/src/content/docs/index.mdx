import { Card, CardGrid } from '@astrojs/starlight/components';

ecc runs `claude` headless, talks to it over pipes in its stream-json protocol, and draws the conversation in an ordinary Emacs buffer. The transcript is read-only text, so `isearch`, `occur` and `M-w` work in it. A permission request, a diff or a plan is answered with one key, in the transcript or from the file you are editing.

<CardGrid>
  <Card title="Answer from any buffer">
    The mode line counts the requests waiting in every session, and `C-c c a` allows
    the oldest from wherever you are.
    [Permissions and plans](/emacs-claude-code/features/permissions/)
  </Card>
  <Card title="Review the change">
    Every change of a session in one diff, however it was made. Comment on lines and
    send the comments as one prompt.
    [Reviewing changes](/emacs-claude-code/features/review/)
  </Card>
  <Card title="Send from your code">
    Send the region, fix the error at point, or write `@region`, `@cursor` and
    `@diagnostics` in a prompt.
    [Sending from your code](/emacs-claude-code/features/send/)
  </Card>
  <Card title="Several sessions">
    A dashboard, a tab for each session, and a mark on each session waiting for you.
    [Session management](/emacs-claude-code/features/sessions/)
  </Card>
  <Card title="Hand over to the terminal">
    `ecc-tui-open` hands the conversation to the CLI's own interface, and
    `ecc-tui-return` takes it back.
    [Handing over](/emacs-claude-code/features/sessions/#handing-over-to-the-terminal)
  </Card>
  <Card title="Off until you turn it on">
    Requests are denied unless you allow them. The MCP server is off, and evaluating
    Elisp is a separate opt-in.
    [Configuration](/emacs-claude-code/reference/configuration/)
  </Card>
</CardGrid>

ecc needs Emacs 29.1 or later and the `claude` CLI, and no other package. Start with the
[installation](/emacs-claude-code/start/installation/), then [a first session](/emacs-claude-code/start/first-session/).
