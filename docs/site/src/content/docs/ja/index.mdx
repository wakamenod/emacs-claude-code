ecc は `claude` をヘッドレスで動かし、stream-json プロトコルを用いてパイプ経由で通信し、会話を通常の Emacs バッファに直接描画します。ターミナルエミュレータは不要です。権限リクエストや diff、プランの確認も、トランスクリプト上や現在編集中の任意のバッファから、キー入力ひとつで応答できます。

まずは[概要](/emacs-claude-code/ja/start/overview/)をご覧ください。続いて[インストール手順](/emacs-claude-code/ja/start/installation/)をご確認いただけます。リファレンスにはすべてのコマンド、設定項目、キーバインドを掲載しています。
