ecc は `claude` をヘッドレスで動かし、その stream-json プロトコルでパイプ越しに
やりとりし、会話を普通の Emacs バッファのテキストとして描きます。ターミナルエミュ
レータは使いません。権限リクエストも diff もプランも、トランスクリプトから、ある
いは今編集しているどのバッファからでも、キー一つで答えられます。

まず[概要](/emacs-claude-code/ja/start/overview/)を読み、
[インストール](/emacs-claude-code/ja/start/installation/)してください。
リファレンスにはコマンド、設定、キーの全件があります。
