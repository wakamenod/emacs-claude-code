import { Card, CardGrid } from '@astrojs/starlight/components';

ecc は `claude` をヘッドレスで起動し、stream-json プロトコルでパイプ越しにやり取りして、会話を普通の Emacs バッファに描画します。トランスクリプトは読み取り専用のテキストなので、`isearch`、`occur`、`M-w` が使えます。権限のリクエスト、diff、プランには、トランスクリプトからでも編集中のファイルからでも、キー 1 つで答えられます。

<CardGrid>
  <Card title="どのバッファからでも応答">
    モードラインに全セッションの応答待ちのリクエストの数が出て、`C-c c a` でどこからでも最も古いものを許可できます。
    [権限とプラン](/emacs-claude-code/ja/features/permissions/)
  </Card>
  <Card title="変更をレビュー">
    セッションの変更を、どう変えたかにかかわらず 1 つの diff で表示します。行にコメントを付け、1 つのプロンプトとして送れます。
    [変更のレビュー](/emacs-claude-code/ja/features/review/)
  </Card>
  <Card title="コードから送る">
    リージョンを送る、ポイントのエラーを直す、プロンプトに `@region`・`@cursor`・`@diagnostics` を書く。
    [コードから送る](/emacs-claude-code/ja/features/send/)
  </Card>
  <Card title="複数のセッション">
    ダッシュボード、セッションごとのタブ、応答待ちのセッションに付く印。
    [セッション管理](/emacs-claude-code/ja/features/sessions/)
  </Card>
  <Card title="ターミナルへ引き渡す">
    `ecc-tui-open` で会話を CLI 本来の画面に引き渡し、`ecc-tui-return` で取り戻します。
    [引き渡し](/emacs-claude-code/ja/features/sessions/#ターミナルへ引き渡す)
  </Card>
  <Card title="有効にするまでオフ">
    リクエストは許可しない限り拒否されます。MCP サーバーは無効で、Elisp の評価はさらに別に有効にします。
    [設定](/emacs-claude-code/ja/reference/configuration/)
  </Card>
</CardGrid>

必要なのは Emacs 29.1 以降と `claude` CLI だけで、ほかのパッケージは要りません。
まず[インストール](/emacs-claude-code/ja/start/installation/)、次に[最初のセッション](/emacs-claude-code/ja/start/first-session/)へ進んでください。
