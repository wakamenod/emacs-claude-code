import { Card, CardGrid } from '@astrojs/starlight/components';

ecc は `claude` をヘッドレスで起動し、stream-json プロトコルでパイプ越しにやり取りして、会話を普通の Emacs バッファに描画します。トランスクリプトは読み取り専用のテキストなので、`isearch`、`occur`、`M-w` が Emacs のほかの場所と同じように使えます。権限の確認、diff、プランには、トランスクリプトからでも編集中のファイルからでも、キー1 つで答えられます。

<CardGrid>
  <Card title="どのバッファからでも応答">
    保留中の権限リクエストはすべてのモードラインに表示され、`C-c c a` を押せばバッファを切り替えずに許可できます。
    [キーバインド一覧](/emacs-claude-code/ja/reference/key-bindings/)
  </Card>
  <Card title="変更内容を diff で正確に把握">
    セッションの変更をすべて 1 つの diff で確認し、ハンクごとにコメントを付けて、1 つのプロンプトとして送り返せます。
    [レビューとプランモード](/emacs-claude-code/ja/features/review/)
  </Card>
  <Card title="エディタの文脈を直接送信">
    `@region`・`@cursor`・`@diagnostics` はプロンプトの送信前に展開されます。回答をコードのすぐ上にオーバーレイで表示することもできます。
    [プロンプトとトランスクリプト](/emacs-claude-code/ja/features/prompt/)
  </Card>
  <Card title="複数セッションを並行管理">
    1 つにまとまったダッシュボード、セッションごとのタブ、応答待ちのセッションを示す表示で、並行する複数のタスクを追えます。
    [セッション管理](/emacs-claude-code/ja/features/sessions/)
  </Card>
  <Card title="ターミナルへ引き渡す">
    `ecc-tui-open` で会話を CLI 本来の画面に引き渡し、`ecc-tui-return` で Emacs に戻します。
    [Transient メニュー](/emacs-claude-code/ja/features/menu/)
  </Card>
  <Card title="デフォルトで安全">
    権限の確認はデフォルトで拒否、ループバック MCP サーバーはデフォルトで無効です。Elisp の評価には明示的な許可が必要です。
    [設定リファレンス](/emacs-claude-code/ja/reference/configuration/)
  </Card>
</CardGrid>

必要なのは Emacs 29.1 以降と `claude` CLI だけで、外部パッケージは要りません。
まず[概要](/emacs-claude-code/ja/start/overview/)を読み、次に[インストール手順](/emacs-claude-code/ja/start/installation/)を確認してください。
