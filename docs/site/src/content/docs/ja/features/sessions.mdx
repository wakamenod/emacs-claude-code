セッションは、実行中の `claude` プロセス、そのバッファ、セッション名からなります。プロジェクトで最初のセッションにはプロジェクトのディレクトリ名が付き、2 つ目以降は名前を尋ねます。セッションを kill するとプロセスは止まりますが、会話はディスクに残ります。

| キー | コマンド | 動作 |
|---|---|---|
| `C-c c c` | `ecc-start` | 今のバッファのプロジェクトでセッションを開始（`C-u` でディレクトリを選ぶ） |
| `C-c c r` | `ecc-resume` | 会話を再開（`C-u` で分岐） |
| `C-c c R` | `ecc-rename-session` | セッションの名前を変更 |
| `C-c c v` | `ecc-show-session` | セッションのウィンドウを表示し、ポイントをプロンプトへ移す |
| `C-c c i` | `ecc-interrupt` | ターンを中断。そこまでの作業は残る |
| `C-c c ?` → `k` | `ecc-kill` | プロセスを止め、セッションのバッファを kill |
| `C-c c t` | `ecc-tui-open` | [ターミナルへ引き渡す](#ターミナルへ引き渡す) |

## セッションを始める場所

`C-c c c` は、今のバッファのファイルかディレクトリのプロジェクトでセッションを始めます。どちらも持たないバッファ（トランスクリプト、ダッシュボード、`*scratch*`）からは、直近にそれを持っていたバッファを使います。`C-u C-c c c` ではディレクトリを尋ねます。

:::caution[ディレクトリは CLI の起動時に決まります]
セッションを別のディレクトリへ移すことはできません。違うプロジェクトで始めてしまったら、kill してそちらで始め直してください。ディレクトリはエコーエリアに、プロジェクト名はヘッダー行に表示されます。
:::

## 会話を再開する

`C-c c r`、またはメニューの `r` で、この Emacs のセッションを先に、続いてこのプロジェクトで記録された会話を、最近のものから並べます。

![会話再開メニュー: 5 つの会話とそれぞれの状態アイコンが並んでいる様子](../../../../assets/resume.png)

| アイコン | 状態 |
|---|---|
| ▶ | この Emacs で実行中 |
| ● | 停止しているが、バッファはこの Emacs にある |
| ◉ | 別のプロセスで実行中 |
| ↺ | ディスクに記録されている |

各項目には、名前、最後に使った日時、ディレクトリか最初のプロンプトが表示されます。メニューの `-f` か `C-u C-c c r` では、選んだ会話を続けるのではなく、そこから新しい会話を分岐させます。

:::caution[実行中の会話を再開すると分岐します]
2 つのプロセスが 1 つのセッション ID に書き込むと記録が分岐し、CLI はファイルをロックしません。そうした会話には ◉ が付き、ecc は再開する前に確認します。
:::

記録は `~/.claude/projects` にあるので、ターミナルのクライアントで始めた会話も並びます。`C-c c h` は、プロセスを起動せずに記録を読むために開きます。そこで `r` を押すと再開します。CLI のプロセスが落ちたときは、ecc が再開するかを尋ねます。

## ターミナルへ引き渡す

`C-c c t` は会話を [ghostel](https://github.com/dakra/ghostel) に引き渡し、CLI 本来の画面を Emacs のバッファに表示します。会話が分岐しないよう、ecc は先にターンを中断して自分のプロセスを止めます。トランスクリプトはターミナルの会話を追い続けます。

<Video name="handover" label="セッションがターミナルへ引き渡され、CLI 本来の画面が表示されて会話が継続される様子" />

メニューの `u`（`ecc-tui-return`）は、ターミナルで増えたやり取りを読み込み、Emacs でセッションを再開します。ターミナルがまだ動いていれば、終了したときにセッションが戻ります。

## 再起動後にセッションを戻す

ecc は、開いている Space とセッションを `user-emacs-directory` の `ecc-state.eld` に保存します。セッションやタブを開閉するたびに書き直します。`M-x ecc-restore` で元に戻します。

- Space は元の順に、そのセッションとともに開きます。`ecc-use-spaces` がオフのときは、セッションだけが戻ります。
- 各セッションは停止した状態で戻ります。CLI が起動するのは、プロンプトを送るか `R` を押したときです。
- すでに開いているセッションや、ディレクトリがなくなったセッションは飛ばします。2 回実行しても問題ありません。

自分で kill したセッションは保存されません。前の Emacs が保存したセッションは、復元するまでファイルに残ります。起動のたびに復元するには、init ファイルから `(ecc-restore)` を呼び出してください。

## 過去の会話を検索する

`C-c c /`（`ecc-search`）は、このプロジェクトで記録された会話のプロンプトと返答を検索します。`C-u` ではすべてのプロジェクトを検索します。大文字と小文字を区別せず、文字列そのままで照合します。ツールの結果やファイルの中身は検索しません。

```
3 sessions said permission prompt in ~/Projects/emacs-claude-code/

Permission prompt rendering  2026-09-08 14:07  2d4f54c9  2 hits
    › how does the permission prompt decide which diff to show?
    ‹ …the block is drawn by `ecc-perm.el`, and a permission prompt keeps the tool input…

Dashboard columns  2026-09-06 10:22  f6743727  1 hit
    ‹ …an idle row is dimmed, and a permission prompt puts `!` in the gutter…
```

`›` は自分のプロンプト、`‹` は Claude の返答です。`RET` か `o` で会話を開き、`n` と `p` で会話の間を移動し、`g` で検索し直します。巻き戻したり放棄したりしたブランチも検索します。

## ダッシュボード

`C-c c B`（`ecc-dashboard`）で、この Emacs のセッションを一覧します。

![ダッシュボード: 回答待ち、実行中、アイドル、終了済みの 4 つのセッションが一覧表示されている様子](../../../../assets/dashboard.png)

各行には、名前、状態、プロジェクト、モデル、最後のプロンプト、最後に答えた時刻、コストが並びます。応答待ちのセッションが先頭に来て、`!` が付きます。ヘッダー行には、状態ごとの数、コストの合計、レート制限が出ます。

| キー | 動作 |
|---|---|
| `RET` | そのセッションへ切り替え |
| `+` | セッションを開始 |
| `k` | セッションを停止（先に確認）。記録は残る |
| `D` | セッションの記録をディスクから削除 |
| `r` / `R` | セッションの名前を変更 / 再開 |
| `a` / `d` | 最も古いリクエストを許可 / 拒否（[詳細](/emacs-claude-code/ja/features/permissions/#リクエストに答える)） |
| `C` / `S` | [ケイパビリティ](/emacs-claude-code/ja/features/other/#ケイパビリティ) / スキルを表示 |
| `U` | [使用量](/emacs-claude-code/ja/features/other/#使用量)を表示 |
| `g` | 更新 |

## タブライン

セッションウィンドウには、そのプロジェクトのセッションごとにタブが並びます。

![4 つのタブが表示され、それぞれの動作状態に応じて色分けされているセッションウィンドウ](../../../../assets/tabs.png)

| 印 | 状態 | 色 |
|---|---|---|
| `⚠` | 応答待ち | 点滅する警告色 |
| `▶` | 作業中 | 緑 |
| `✗` | プロセスが終了 | 赤 |
| `○` | 復元済みで未起動 | 薄い色 |
| （なし） | アイドル | 薄い色 |

ウィンドウに表示中のセッションのタブは、太字に下線付きです。`(setq ecc-tab-blink nil)` で点滅を止められます。

タブをクリックすると、ウィンドウがそのセッションに切り替わります。セッションバッファでは、`C-c C-t` でウィンドウのタブから、`C-u C-c C-t` ですべてのセッションから選べます。Space がオンなら、別のプロジェクトのセッションはそのプロジェクトの Space に開きます。タブの `x` は確認してからセッションを止め、ウィンドウは隣のタブに移ります。`(setq ecc-tab-close-confirm nil)` で確認を省けます。

<Video name="switch" label="セッションウィンドウが別のセッションに切り替わり、選択タブが greet から notes へ移動してトランスクリプトが置き換わる様子" />

`(setq ecc-tab-line-scope 'all)` で、どのタブラインにもすべてのセッションを並べます。Emacs のタブバーにもセッションの状態を示すには、`ecc-tab-bar-state` を `t` にします。あわせて `tab-bar-tab-name-function` を `#'ecc-tab-bar-tab-name` にしてください。

タブの下のヘッダー行には、セッションの状態、プロジェクト、コンテキストウィンドウの残りが表示されます。残りは少なくなると黄色、さらに赤に変わります。

## 応答待ちのセッション

応答待ちのセッションは 3 か所に示されます。

- すべてのモードラインの `⚠ecc:N` が、全セッションの応答待ちのリクエストを数えます。クリックするとダッシュボードが開きます。
- タブが点滅します。
- 通知が届きます。`ecc-notify-level`（`'message`、`'pulse`、`'desktop`、`nil`）と `ecc-notify-events` で決めます。

`C-c c n` で次の応答待ちのリクエストへ、`C-c c N` でこのプロジェクトの次のリクエストへジャンプします。
