## ケイパビリティ

メニューかダッシュボードで `C` を押すと、CLI がセッションについて報告したものを一覧します。スキル、サブエージェント、スラッシュコマンド、MCP サーバー、プラグインが、出どころ（プロジェクト、自分の設定、プラグイン、組み込み）ごとにまとまって並びます。

<Video name="capabilities" label="ケイパビリティバッファ: 各グループが開閉されている様子" />

`TAB` でグループを開閉し、`RET` でポイントの項目を表示し、`g` で更新します。セッションの最初のターンより前は、一覧は空です。

## 使用量

`C-c c U`（`ecc-usage`）で、Claude Code のプランの使用量とレート制限を表示します。

![使用量レポートのポップアップ: レート制限枠、セッションのコスト、制限を消費している要因が表示されている様子](../../../../assets/usage.png)

数値は CLI から取得したもので、claude.ai の Settings → Usage と一致します。セッションが動いていなければ、ecc は CLI を起動して尋ね、すぐに止めます。プロンプトは送らないので、トークンは消費しません。

| キー | 動作 |
|---|---|
| `g` | 更新 |
| `b` | 制限を消費しているものの内訳を表示・非表示 |
| `q` | レポートを閉じる |

内訳に入るのは、このマシンで記録されたセッションだけです。`ecc-usage-display` で、レポートをウィンドウに出すか posframe のポップアップに出すかを決めます。
