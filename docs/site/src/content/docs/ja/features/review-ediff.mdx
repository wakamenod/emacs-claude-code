`ecc-review-style` は、[レビューのメニュー](/emacs-claude-code/ja/features/review/#比べる対象を選ぶ)から開くレビューの表示方法を決めます。デフォルトの `'diff` は diff バッファです。`'ediff` にすると、2 つの側を ediff で表示します。

```elisp
(setq ecc-review-style 'ediff)
```

メニューの `-e` で、1 つのレビューだけ表示方法を切り替えられます。

レビューのすべてのファイルが 1 つの ediff セッションに入ります。左のバッファに変更前、右のバッファに変更後の内容が並び、各ファイルの前に `═══ path ═══` の行が入ります。`n` と `p` は、ファイルをまたいでレビューのすべての差分を移動します。バイナリのファイルや `ecc-review-max-bytes` を超えるファイルは、区切りの行だけになります。どちらの側も読み取り専用なので、ediff のコピーのコマンドは働きません。コメントを付けて送り、ファイルの編集は Claude に任せます。

レビューはフレーム全体を使います。画面上のウィンドウの中に開くには、`ecc-review-ediff-full-frame` を `nil` にします。送信、`C-c C-k`、`q` で、開く前のウィンドウの配置に戻ります。

## 画面の並び

レビューは、変更前を上、変更後を下に置き、Claude の返答の欄を右に置いて開きます。`|` で 2 つの側を左右に並べ、欄はその下に移ります。もう一度 `|` を押すと上下に戻ります。左右に並べて開くには:

```elisp
(setq ecc-review-ediff-layout 'side-by-side)   ; the default is 'stacked
```

各ウィンドウのヘッダー行にはキーが並び、キーボードのあるウィンドウでは末尾に `3/12` のような現在位置が出ます。ediff のコントロールパネルは隠れています。`?` ですべてのキーとともに表示し、もう一度押すと隠します。ほかの ediff セッションは、自分で設定したウィンドウ配置のままです。

各ファイルはそのメジャーモードで色付けされ、変わった語は太字になります。

## 2 つのウィンドウで読む

キーボードは変更後の側から始まります。どのキーも両方のウィンドウで使え、数字で回数を指定できます。`3j` は 3 番目の差分へジャンプします。

ポイントの動きがレビューを動かします。ポイントが差分に入るとそれが現在の差分になり、もう一方のウィンドウは対応する行が同じ高さに来るようにスクロールします。`n` と `p` は、ポイントより下の次の差分、上の前の差分へ移ります。`C-v` やマウスで一方だけをスクロールしても、もう一方は動きません。`v` と `V` は両方をスクロールし、`C-l` で位置をそろえ直します。

`RET` は、ポイントのある行でファイルを今の内容のまま別のフレームに開きます。レビューのフレームとキーボードはそのままです。

| キー | 動作 |
|---|---|
| `c` | ウィンドウではポイントのある行にコメント。`?` で出したパネルでは現在の差分にコメント、またはそこにある Claude の最新のコメントに返信。もう一度押すと編集 |
| `{` / `}` | 前 / 次のコメント |
| `l` | コメントへジャンプ |
| `x` | ポイントのある行のコメント、なければ現在の差分のコメントを削除（`C-u x`: どのコメントでも）。diff バッファでは `d` |
| `a` | Claude のコメントの表示・非表示 |
| `n` / `p` / `j` | 次 / 前の差分、または番号の差分 |
| `v` / `V` | 両方のウィンドウをスクロール |
| `RET` | ファイルを別のフレームに開く |
| `s` / `/` | [ファイルを一覧・絞り込む](/emacs-claude-code/ja/features/review/#ファイルを一覧し絞り込む) |
| `T` / `t` / `M` | [Claude と話す](/emacs-claude-code/ja/features/review-claude/#レビューから-claude-と話す) |
| `u` / `d` | 返答の欄を戻す / 進める |
| `y` | 返答の欄に出ている、Claude が待っているものに答える |
| `\|` | 2 つの側を上下と左右で切り替える |
| `!` | ファイルを読み直す（`g` はない） |
| `C-c C-c` | コメントをプロンプトとして送信（`C-u C-c C-c` で送信前に編集） |
| `C-c C-k` | レビューとコメントを破棄 |
| `q` | レビューを終える |
| `?` | コントロールパネルの表示・非表示 |

両方の側にある行には、コメントを付ける対象がないので、`c` はそう伝えます。コメント、送信、[ファイルの変更への追従](/emacs-claude-code/ja/features/review/#ファイルの変更に追従する)は diff バッファと同じです。読み直しても、現在の差分と各側の位置は保たれます。

## 返答の欄

ediff がフレームを使っている間、セッションは見えません。diff の横の欄に、セッションの最新の返答が届くそばから表示されます。ツールの呼び出しは 1 つずつ 1 行で出ます。

```
› Next stop.
The cache is now keyed by path, so a renamed file is read again.
  review_navigate → ecc-review-ediff.el:248
  review_comment → ecc-review-ediff.el:252: This drops the old entry
```

ターンごとに内容は入れ替わり、会話の全体はトランスクリプトに残ります。Claude が許可を求めたとき、質問したとき、承認するプランがあるときは、欄にその内容が出て、`y` で答えられます。欄が選択されることはありません。`u` と `d` でレビューから欄をスクロールできます。前に戻すと、末尾がまた見えるまで欄は末尾を追いません。

| 変数 | 既定値 | 説明 |
|---|---|---|
| `ecc-review-talk-reply-width` | `75` | 右に置く欄の幅。diff に 80 桁を残せない狭いフレームでは、欄は下に移る |
| `ecc-review-talk-reply-height` | `12` | 下に置く欄の高さ。`nil` で欄を出さない |
| `ecc-review-talk-reply-place` | `'auto` | `'frame` はレビューごとに専用のフレームに欄を出す。そのフレームはフォーカスを取らない |
