Claude はファイルを編集したりコマンドを実行したりする前に許可を求めます。リクエストは diff やコマンドとともにトランスクリプトに表示され、そのセッションはタブ、モードライン（`⚠ecc:N`）、[サイドバー](/emacs-claude-code/ja/features/spaces/#サイドバー)で応答待ちとして示されます。ユーザーが許可しない限り、何も許可されません。答えられなくなったリクエストは拒否として記録されます。

## リクエストに答える

<Video name="permission" label="ファイルの書き込み権限リクエストに対し、a で許可してターンが完了する様子" />

トランスクリプトでリクエストの上にポイントがあるとき:

| キー | 動作 |
|---|---|
| `a` / `d` | 1 回だけ許可 / 拒否 |
| `A` | このセッションの間、このツールを常に許可 |
| `u` | ターンが終わるまで、すべてのリクエストを許可 |
| `r` | 一致するルールを許可（プロジェクトの設定に保存） |
| `RET` | 提案の内容を確認 |
| `c` | [提案にコメント](#許可する前に提案を編集する)し、そのコメントを付けて拒否 |
| `e` | 許可する前に[提案を編集](#許可する前に提案を編集する) |

ほかの場所から:

| 場所 | キー |
|---|---|
| プロンプト領域 | `C-c C-a` / `C-c C-d`: ポイントのあるリクエスト、なければこのセッションの最も古いもの、それもなければ全セッションで最も古いもの |
| どのバッファでも | `C-c c a` / `C-c c d`: 最も古いリクエスト。`C-c c n` でそこへジャンプ |
| ダッシュボードとサイドバー | そのセッションの行で `a` / `d` |
| メニュー | `A` でセッションの応答待ちのリクエストをすべて許可。`-r` でツールも記憶 |

どのバッファからでも、ダッシュボードやサイドバーからでも、答える前に何に答えるのかを確認します。確認を省くには `ecc-answer-confirm` を `nil` にします。`ecc-answer-exclude-tools`（デフォルトは `Bash`）のツールには答えません。シェルコマンドはトランスクリプトで読んでから答えるためです。

## 質問

Claude が質問したときは、その上で `RET` を押すと回答用のバッファが開きます。`1`〜`9` で選択肢を選び、`SPC` で複数選択の項目を切り替え、`o` で自由に回答を書き、`C-c C-c` で送ります。どのバッファからでも、`C-c c 1`〜`C-c c 4` で選択肢を選べます。

<Video name="question" label="2 問ある質問: 1 問目で選択肢を 1 つ選び、2 問目で 2 つをオンにして回答を送信する様子" />

## 許可する前に提案を編集する

<Video name="proposal" label="提案された Write の内容をバッファで書き換え、書き換えた内容で許可する様子" />

リクエストで `c` を押すと、その変更を[レビュー](/emacs-claude-code/ja/features/review/)で開きます。送ったコメントは拒否の理由になるので、Claude は提案をやり直せます。

`e` は提案された内容を、対象ファイルのメジャーモードで開きます。`C-c C-c` で Claude の内容の代わりに自分の内容で変更を許可し、変えた箇所を Claude に伝えます。`C-c C-k` ではリクエストを応答待ちのまま残します。

## プランモード

Claude がプランモードを抜けると、プランがセッションの横の編集できるバッファに開きます。

<Video name="plan" label="プランを専用のバッファで開き、行にコメントを付け、権限モードを選んで、コメント付きでプランを返す様子" />

フィードバックは、行へのコメント、プラン中の `@claude: …` の行、プランの編集のいずれかで伝えます。フィードバックがあれば、`C-c C-c` でそれを送り、修正を求めます。なければプランを承認し、`C-c C-p` で選んだ権限モード、選ばなければ `ecc-plan-default-mode`（`"acceptEdits"`）に切り替えます。

| キー | 動作 |
|---|---|
| `C-c C-c` | 承認、またはフィードバックを送信 |
| `C-c C-k` | 理由を付けて却下（フィードバックも含む） |
| `C-c C-a` / `C-c C-r` | この行のコメントを追加 / 削除 |
| `C-c C-d` | 自分の編集と提案時のプランの diff |
| `C-c C-p` | 承認するときの権限モードを選ぶ |
| `C-c C-n` | 前のプランから変わった次の行 |

修正されたプランでは、変わった行がマージンに示され、ヘッダー行に `+N −N` が出ます。トランスクリプトで `P` を押すとプランへジャンプします。

## 権限モード

プロンプト領域の下のフッターに、セッションの権限モードが表示されます。セッションバッファで `S-TAB` を押すと、`default`、`acceptEdits`、`plan`、`auto` の順に切り替わります。`bypassPermissions` はこの切り替えに入っていないので、`M-x ecc-set-permission-mode`（メニューの `p`）で選びます。新しいセッションが始まるときのモードは `ecc-permission-mode` で決めます。
