Claude が提案するファイルの変更と、プランモードを抜けるときに提案するプランは、どちらも返答を待つ状態になります。返答する前に、提案にコメントを付けたり、編集したり、差し戻したりできます。

## 適用前の提案をレビューする

<Video name="proposal" label="提案された Write の内容をバッファで書き換え、書き換えた内容で許可する様子" />

トランスクリプトでツールの許可リクエストが保留中のとき、リクエストノードで `c` を押すとその変更をレビューでき、`e` で提案された内容を開けます（[プロンプトとトランスクリプト](/emacs-claude-code/ja/features/prompt/#回答待ちリクエストノード上での操作)を参照）。

ここでのコメントは**拒否の理由**として送信されるので、書き込んだあとに直させるのではなく、Claude に提案し直してもらえます。

`e` は対象ファイルのメジャーモードで提案を開きます。`C-c C-c` は Claude のテキストの代わりに自分のテキストで変更を許可し、変えた部分の diff を送ります。`C-c C-k` はリクエストを保留のままにします。

## プランモード

プランモードを抜けると、プランがリクエストとして送られます。ecc はそれをセッションの横の編集できるバッファで開きます。

<Video name="plan" label="プランを専用のバッファで開き、行にコメントを付け、権限モードを選んで、コメント付きでプランを返す様子" />

フィードバックの方法は 3 通りあります。行へのコメント（`C-c C-a`、削除は `C-c C-r`）、行内の `@claude: …` マーカー、プラン自体の編集（`C-c C-d` で差分を表示）です。

フィードバックがあれば、`C-c C-c` はそれを添えてプランを返し、修正を求めます。フィードバックがなければプランを承認し、権限モードを尋ねます。`C-c C-p` で権限モードを選べ、選ばなければ `ecc-plan-default-mode`（デフォルト `"acceptEdits"`）を使います。

| キー | 動作 |
|---|---|
| `C-c C-c` | 承認。フィードバックがあればそれを送信 |
| `C-c C-k` | 理由を添えて却下（フィードバックも含める） |
| `C-c C-a` / `C-c C-r` | この行のコメントを追加 / 削除 |
| `C-c C-d` | 提案されたプランと自分の編集の差分を表示 |
| `C-c C-p` | 承認するときの権限モードを選ぶ |
| `C-c C-n` | 前のプランから変わった次の行へ |

新しいプランでは、変わった行がマージンに印で示され、ヘッダーラインに `+N −N` が表示されます。
