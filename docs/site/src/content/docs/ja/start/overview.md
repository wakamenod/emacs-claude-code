ecc は `claude` をヘッドレスで起動し、stream-json プロトコルでパイプ越しにやり取りして、会話を普通の Emacs バッファに描画します。ターミナルエミュレータは使いません。

セッションバッファの上部にはトランスクリプトが、区切り線の下にはプロンプトの入力領域が表示されます。トランスクリプトは読み取り専用のテキストなので、`isearch`、`occur`、narrowing、`M-w` が Emacs のほかの場所と同じように使えます。トランスクリプトは入力欄ではないため、`n`、`p`、`TAB`、`a`、`d` といった1 文字のキーがそのままコマンドになります。プロンプト領域では普段どおりに文字を入力できます。

使い始める前に:

- **権限の確認は、デフォルトでは拒否になります。** セッション内では `C-c C-a`（許可）か `C-c C-d`（拒否）で答えます。`ecc-global-map` を使えば、どのバッファからでも答えられます。
- **必要なのは Emacs 29.1 と `claude` CLI だけです。** 外部パッケージは必要ありません。
- **CLI 本来の画面を使いたいときは、`ecc-tui-open` でセッションをターミナルクライアントに引き渡せます。** `ecc-tui-return` で元に戻ります。

まずは[インストール手順](/emacs-claude-code/ja/start/installation/)をご覧ください。使えるコマンドの一覧は [Transient メニュー](/emacs-claude-code/ja/features/menu/)で確認できます。
