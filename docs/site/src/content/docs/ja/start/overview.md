1 つの作業を最初から最後までたどります。ecc が[インストール](/emacs-claude-code/ja/start/installation/)済みで、`ecc-global-map` が `C-c c` に割り当てられているものとします。

## セッションを始める

プロジェクトのファイルを開き、`C-c c c` を押します。セッションがファイルの横に開き、プロジェクトのディレクトリ名が付きます。始めたあとはディレクトリを変えられないので、正しいプロジェクトのバッファから始めてください。

セッションバッファは、上がトランスクリプト、下がプロンプト領域です。トランスクリプトは読み取り専用なので、1 文字のキーがコマンドになります。`n` と `p` で見出しを移動し、`TAB` で畳みます。プロンプト領域では普段どおり入力できます。

## プロンプトを送る

プロンプト領域に入力して `C-c C-c` を押します。`RET` は改行です。答えはトランスクリプトに届くそばから表示されます。Claude が動いている間に送ったプロンプトはキューで待ちます。

コードを含めるには、プロンプトに `@region` や `@cursor` と書くか、ファイルから `C-c c ?` → `g` でリージョンを送ります。[コードから送る](/emacs-claude-code/ja/features/send/)を参照してください。

## 権限を許可する

Claude がファイルを編集したりコマンドを実行したりする前に、トランスクリプトに diff やコマンド付きのリクエストが出て、セッションのタブが点滅します。答えるまで何も起きません。

リクエストの上で `a` を押すと 1 回だけ許可し、`d` で拒否します。プロンプト領域では `C-c C-a` と `C-c C-d`、どのバッファからでも `C-c c a` と `C-c c d` で同じことができます。提案を先に編集するなど、ほかの答え方は[権限とプラン](/emacs-claude-code/ja/features/permissions/)にあります。

## 変更をレビューする

`C-c c D D` で、セッションの変更をすべて 1 つの diff で表示します。行の上で `c` を押してコメントを付け、`C-c C-c` ですべてのコメントを 1 つのプロンプトとして Claude に送ります。[変更のレビュー](/emacs-claude-code/ja/features/review/)を参照してください。

トランスクリプトで `F` を押すと、セッションが触れたファイルを並べた Files セクションへジャンプします。

## 終える

`C-c c ?` → `k` でセッションを止め、バッファを kill します。会話はディスクに残り、あとで `C-c c r` で再開できます。Emacs でもターミナルのクライアントでもかまいません。

プロジェクトにはそれぞれ専用のタブがあり、これを Space と呼びます。[Space で 1 つの仕事を終えるまで](/emacs-claude-code/ja/usecases/spaces/)で、1 つの作業の流れを追っています。
