ecc は `claude` をヘッドレスで動かし、stream-json プロトコルを用いてパイプ経由で通信し、会話を通常の Emacs バッファに描画します。ターミナルエミュレータは不要です。

セッションバッファは、上部に会話のトランスクリプト、区切り線を挟んだ下部にプロンプト入力領域を表示します。トランスクリプトは読み取り専用テキストなので、`isearch`、`occur`、narrowing、`M-w` など Emacs 標準の操作がそのまま利用できます。トランスクリプト上では直接文字入力を受け付けないため、単一キー（`n`、`p`、`TAB`、`a`、`d` など）がそのままコマンドとして機能します。プロンプト領域では通常の文字入力が保持されます。

利用開始にあたって知っておくべきポイント:

- **ツールの実行権限プロンプトは、デフォルトで「拒否（deny）」に設定されています。** セッション内からは `C-c C-a`（許可）/ `C-c C-d`（拒否）で応答できるほか、`ecc-global-map` を割り当てておけば任意のバッファから応答可能です。
- **必要なのは Emacs 29.1 以降と `claude` CLI だけです。** 追加の外部パッケージは一切必須ではありません。
- **CLI 本来の TUI が必要なときは `ecc-tui-open` でターミナルクライアントへセッションを一時的に引き渡し**、作業後に `ecc-tui-return` で Emacs へ戻せます。

まずは[インストール手順](/emacs-claude-code/ja/start/installation/)をご覧ください。すべての操作は[Transient メニュー](/emacs-claude-code/ja/features/menu/)からも実行できます。
