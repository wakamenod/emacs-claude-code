ここでは 1 ターンを最初から最後までたどります。ecc は
[インストール済み](/emacs-claude-code/ja/start/installation/)で、`claude` CLI が
ターミナルで動くことを前提にします。

## 始める

作業したいプロジェクトのファイルを開いて、次を実行します。

```
M-x ecc-start
```

セッションは現在のバッファのプロジェクトをディレクトリに取り、そのディレクトリ
名を自分の名前にします。同じプロジェクトで二つ目を始めるときは、一つ目と区別す
るための名前を訊かれます。プレフィックス引数（`C-u M-x ecc-start`）を付けると、
ディレクトリと名前の両方を訊きます。

セッションバッファが現れ、ポイントはすでにプロンプト領域にあります。

## 今見ているもの

```
  トランスクリプト     読み取り専用。一文字キーが効く
  ────────────         区切り線
  プロンプト領域       入力する場所。メジャーモードのキー
  ────────────
  default              フッター。今の権限モード
```

**トランスクリプト**は読み取り専用のテキストです。ここには何も入力しないので、
一文字がそのままコマンドになります。`n` と `p` で見出しを渡り、`TAB` で畳み、
`RET` でポイントの下にあるものを開きます。

**プロンプト領域**が束縛しているのは `RET`、`TAB`、`C-c` 配下だけです。書いてい
る間、文字は文字のままです。空の領域に見えているプレースホルダはゴーストテキス
トで、中身ではありません。消す必要はありません。

**フッター**はセッションの権限モードを示します。`S-TAB` がこれを巡回させます。
どちらの領域からでも効きます。

## 送ってみる

プロンプト領域に書いて `C-c C-c` を押します。

`RET` は改行です。プロンプトは、書いて、直して、読み返してから出すためのもので
す。ターミナルクライアントと同じ挙動がよければ、`ecc-chat-return-sends` を `t`
にすると `RET` が送信になり、改行は `S-RET` に残ります。

書いている間に使えるもの:

- `/` は、そのセッションが実際に持っていると報告したスラッシュコマンドを出しま
  す。固定のリストではなく、そのセッションのスキルやプラグインのコマンドです。
- `@` は参照の始まりです。`@path/to/file` は CLI にそのまま渡ります。`@region`、
  `@cursor`、`@diagnostics` は Emacs 自身が答えるもので、直前まで作業していた
  バッファの引用ブロックに展開されてから送られます。
- `M-p` と `M-n` はプロンプト履歴をたどります。履歴は全セッション共通です。
- `C-c C-q` は送信待ちのものを見せます。ターンの実行中に送っても割り込みにはな
  りません。プロンプトは順番を待ちます。

返答は届くそばから描かれます。方向が違うと思ったら `C-c C-g` でターンを中断でき
ます。

## 権限リクエストに答える

遅かれ早かれ、ターンは止まってツールを使う許可を求めてきます。クライアントが存
在する理由はこの瞬間にあります。

**権限プロンプトの既定は拒否です。** あなたが言うまで何も起きません。

プロンプト領域から、動かずに答える:

| キー | 何をするか |
|---|---|
| `C-c C-a` | 許可する |
| `C-c C-d` | 理由を付けて拒否する |

どちらもポイントの下のリクエストに効き、そこに無ければ最も古い待機中のものに落
ちます。

トランスクリプトでリクエストの上にポイントを置くと、一文字キーでもっと先まで行
けます。

| キー | 何をするか |
|---|---|
| `a` / `d` | 一度だけ許可 / 拒否 |
| `A` | これと、以後これと同種のものすべてを許可 |
| `u` | ターンが終わるまですべて許可 |
| `r` | 自分で書いたルールで許可。プロジェクト設定に保存される |
| `e` | 許可する前に、提案された内容を編集する |
| `c` | 提案にコメントする |
| `RET` | 提案されたものを開く。ファイル、diff、結果の全文 |

Edit や Write なら、`RET` は決める前に変更を diff で見せます。許可すると、その
ファイルを訪れているバッファは自動で revert されます。未保存の変更があるバッファ
は触られず、上書きではなく警告になります。

### 別のバッファから

セッションにいる必要はありません。[インストールのページ](/emacs-claude-code/ja/start/installation/#最初の設定)
の通り `ecc-global-map` を束縛してあれば、編集中のどのバッファからでも
`C-c c a` でどのセッションのものであれ最も古い待機中リクエストを許可し、
`C-c c d` で拒否できます。`C-c c n` は次に待っているセッションへ飛び、
`C-c c b` は全部のダッシュボードを開きます。

## 返ってきた答えを読む

トランスクリプトは木です。ターンがステップを持ち、ステップが実行したツールを持
ちます。

- `TAB` はポイントのノードを畳みます。`1`–`4` はその深さまで開き、`+` と `-` は
  全部を開閉します。
- `n` と `p` は見出し単位、`M-n` と `M-p` は同じ深さの兄弟単位、`^` は親へ。
- `f` は Files セクション（セッションが触ったファイルの全部）へ行き、その行での
  `d` はそのファイルの変更をレビューします。
- `w` はポイントの下のものをコピーします。トランスクリプトはただのテキストなの
  で、`isearch` も `occur` も全体に効きます。
- `i` でプロンプトに戻ります。

ターンがいくつも変更を加えたときは、`C-c ?` から `D`（どこからでもなら
`C-c c D`）で、その**全部**を一枚の diff として開けます。ハンクを渡り歩き、おか
しいところにコメントを付け、全コメントを一つのプロンプトとして送れます。

## 終える、あるいは後で続ける

`C-c ?` がメニューを開きます。メニューはすべてに届き、そのキーを表示します。

- `k` はセッションを止めて忘れます。
- `h` は CLI 自身の記録から過去の会話を、普通のセッションバッファで開きます。
- `r` は再開します。

:::caution[生きているセッションの再開は会話を分岐させます]
まだ生きているセッションに対して二つ目のプロセスが `--resume` を走らせると会話
が分岐し、CLI にはそれを止めるロックがありません。再開の前にセッションを止めて
ください。`ecc-history-resume` は先に確認します。
:::
