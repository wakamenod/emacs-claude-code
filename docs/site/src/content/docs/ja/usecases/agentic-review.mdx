どんなに agent にコードを書いてもらっても、コードの内容を最後に確認するのは人間です（今のところは）。

それなら、レビューも agent に手伝ってもらいましょう。このページでは、1 つの変更を[レビューの中の Claude](/emacs-claude-code/ja/features/review-claude/) と読みます。こちらがレビューを開き、Claude がツアーで案内して行にコメントを付け、こちらは行の上で答え、Claude が頼んだところを直し、新しい差分を読みます。[Emacs の MCP サーバー](/emacs-claude-code/ja/start/installation/#mcp-サーバーの有効化)を有効にしておく必要があります（`ecc-mcp-enabled`）。

ここでのレビューは、`ecc-review-style` を `'ediff` にした [ediff のレビュー](/emacs-claude-code/ja/features/review-ediff/)です。diff バッファのレビューでも同じキーが使えます。

## Claude が変更を加えた

ターンが終わり、Claude がファイルを変更しました。何をしたかはトランスクリプトに書かれています。

## レビューを開く

`C-c c D D` で、[セッションの変更のレビュー](/emacs-claude-code/ja/features/review/#セッションの変更)を開きます。ediff ではレビューがフレーム全体を使い、上に変更前、下に変更後が並び、その横に Claude の[返答の欄](/emacs-claude-code/ja/features/review-ediff/#返答の欄)が出ます。セッションが見えない間、Claude の答えはこの欄に出ます。

「この変更をレビューで案内して」のように普段の言葉で頼んでも開けます。Claude がレビューを開くのは頼まれたときだけで、開くのは diff バッファのレビューです。Claude が ediff を始めることはありません。

## ツアーで読む

レビューで `T` を押すと、レビューのハンクを添えて、変更を重要な順に案内するよう Claude に頼みます。Claude は箇所ごとにレビューをその変更までスクロールし、返答の欄で数文で説明し、注意してほしい行の下に `▎ #2 Claude: text` の形でコメントを付けて、待ちます。`t` で次の箇所を頼みます。そのとき、今どこにいるかも Claude に伝わります。詳しくは [レビューから Claude と話す](/emacs-claude-code/ja/features/review-claude/#レビューから-claude-と話す)を参照してください。

## 行の上で答える

レビューのどちらのウィンドウでも、次のキーを使います。

| キー | 動作 |
|---|---|
| `c` | ポイントのある行にコメント。変更前のウィンドウでは変更前の行に、変更後のウィンドウでは今の行に付く。Claude のコメントだけがある行では、それに返信 |
| `M` | Claude に質問する。リージョンがあるときは、選んだ行について |
| `C-c C-c` | 自分のコメントを 1 つのプロンプトで送る。レビューは開いたまま |
| `y` | 返答の欄に出ている、Claude が待っているもの（許可、質問、プラン）に答える |

`M` はすぐに送られます。コメントは `C-c C-c` まで送られないので、差分を最後まで読んでからまとめて送れます。

## Claude がレビューの中で答える

Claude はこちらの各コメントの下に、字下げした返信を付けられます。対応を終えたコメントは削除することもあります。こちらのコメントを Claude が書いたり書き換えたりすることはありません。それ以外に Claude が話すことは返答の欄に出ます。コードだけを読みたいときは、`a` で Claude のコメントを隠せます。

## Claude が直し、レビューが追従する

Claude がファイルを編集すると、開いているレビューはファイルを読み直します。ツールが終わったとき、ターンが終わったとき、リポジトリのファイルを保存したときです。コメントは保たれ、現在の差分と各側の位置もそのままです。行がなくなったコメントには `[outdated]` が付きます。新しい差分を読み、必要ならまたコメントします。詳しくは[ファイルの変更に追従する](/emacs-claude-code/ja/features/review/#ファイルの変更に追従する)を参照してください。

## 終える

差分が望みどおりになったら、`q` か `C-c C-k` で ediff のレビューを閉じます。ウィンドウの配置は開く前に戻ります。diff バッファでは 2 つのキーの動作が違い、`q` はレビューを隠し、`C-c C-k` はレビューを閉じます。閉じたレビューは送っていないコメントを残し、[レビューメニューの `R`](/emacs-claude-code/ja/features/review/#レビューを再開する) でまた開けます。次のレビューを何もない状態から始めたいときは、Claude にコメントを消すよう頼みます。
