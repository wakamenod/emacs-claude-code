Verified against **Claude Code CLI 2.1.281** and Emacs 30.1.

A maintenance release with three fixes to what 0.3.3 added. Nothing changes a
command, a key, or a setting.

- `RET` on the heading of a Write or a MultiEdit now opens the file at the line
  it changed. Before, it opened at the top when the CLI reported no patch,
  which is always the case for a Write that creates a file.
- A file outside the project is no longer shown as if it were inside it just
  because its path starts with the same letters. With a project at `/tmp/app`,
  `/tmp/application/x.el` was shown as `../application/x.el`.
- `RET` on a diff that was already drawn keeps working after
  `ecc-diff-style` is changed.

See `CHANGELOG.md` for the full record.
