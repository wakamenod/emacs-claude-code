Verified against **Claude Code CLI 2.1.270** and Emacs 30.1.

### Faster

Long sessions used to slow down over time and lag the rest of Emacs. Most of that slowdown is gone.

- A running turn now redraws only from the block that changes, not from the start. Previously, every update deleted and redrew the entire turn ten times a second, which caused turns with hundreds of tool calls to stutter. One redraw of an 800-call turn dropped from 81 ms to 0.2 ms.
- A reply of 8000 deltas went from 1260 ms and 11 garbage collections to 69 ms and one. Previously, every line from the CLI trimmed the session log buffer line by line. In long sessions, that accounted for 88% of the cost per delta, even when the buffer was off screen. Streaming blocks also rejoined their text on every delta. Because garbage collection pauses all buffers, typing in another buffer while a session streams is no longer held up.
- Drawn diffs and fontified Markdown are kept until their text changes. The Files summary diffs a file again only when that file changes. A redraw in a session with three edited files went from 5.7 ms to 1.5 ms.

### Reviewing a whole worktree

`ecc-review-worktree` (`C-c c G`, or `G` in the menu) reviews the git diff of the whole project, not just the files the session touched. It includes every uncommitted change, staged or not, plus untracked files that `.gitignore` does not exclude. A prefix argument asks what to diff against, so `main...HEAD` reviews a branch. You comment on hunks and send them as one prompt, just like `ecc-review`. The two commands have separate buffers.

Run it from a project file rather than a transcript. It uses that buffer's project and sends the comments to a session for that project, starting one if there is none.

### Sessions and windows

- `ecc-focus-project` (`C-c c j`) focuses the frame on one project, and `ecc-toggle` (`C-c c w`) hides and restores its session windows.
- A session's header line and window tab line show the project name. `project.el` decides which sessions belong to a project.

### Skills, plugins and hooks

Emacs now handles three commands that the CLI renders itself and never sends over stream-json:

- `/skills` lists a session's skills and cycles each through `on`, `name-only`, `user-invocable-only`, and `off`.
- `/plugins` browses, installs, and updates plugins and marketplaces.
- `/hooks` lists every hook that would run for a project, grouped by event, and adds, removes, or switches them off.

`/login`, `/logout`, and `/auth-status` are supported as well.

### Breaking

- `ecc-hook-events-enabled` is now `ecc-show-hook-events`. It decides whether hook events are displayed, never whether they run.
- `ecc-review-context-lines` is now a `defvar` rather than a `defcustom`, and its default is 0 rather than 3. It is no longer in the Customize interface. Existing `custom-set-variables` entries still work, and `setq` still widens the hunks.

This release includes eight fixes as well, including a redraw that failed halfway leaving the transcript inside the prompt region, and a running session dropped from the dashboard. `CHANGELOG.md` has the full record.
