Verified against **Claude Code CLI 2.1.274** and Emacs 30.1.

### Spaces: a tab for every project

Every project now has its own tab -- a Space -- and you can arrange the windows inside it however you like. Each tab remembers its layout when you leave and return. Transcripts appear side by side and never stack. `C-c c j` switches to a Space, `C-c c z` fills the tab with a single window, and `C-c c V` resets the window layout. A git worktree is its own Space, displayed under the repository it came from. Setting `(setq ecc-use-spaces nil)` restores the previous layout: side windows with roles, no tabs, no sidebar, and no worktree commands.

**The sidebar.** `C-c c b` opens a narrow sidebar on the left that stays on screen while you work. Numbered projects and worktrees appear at the top, showing each branch and what it is doing. Sessions appear below, showing what each is waiting for. `RET` opens the selected row, `1`-`9` switches to a Space by number, `a` and `d` answer a session, `W` creates a worktree, `K` removes one, and `X` closes a Space. The dashboard is now `C-c c B`.

**Worktrees.** A session can run in its own worktree. In the menu, `W c` checks out a branch beside the repository and starts a session there, `W o` starts a session in a worktree that exists, and `W k` stops the sessions in one and removes it. When the last session in a worktree ends, ecc offers to remove the directory -- the branch always stays, so nothing committed can be lost. With the Emacs MCP server enabled, the model is offered `start_worktree_session`. It names the branch and writes a brief. Emacs then creates the worktree, opens it as a Space, and starts a session there with that brief, instead of running `git worktree add` and carrying one conversation across two checkouts.

### Reviewing in ediff

- Setting `ecc-review-style` to `'ediff` opens `D` and `G` in ediff instead of a single `diff-mode` buffer. Every file in the review is included in one session, so `n` and `p` step through differences across file boundaries. Both sides are read-only, and `?` shows help written for the review rather than ediff's own.
- In a review, `C-c C-c` sends comments immediately instead of opening a buffer to confirm them. `C-u C-c C-c` opens that confirmation buffer when you want to comment on the change as a whole.

### Images and video in the transcript

Images now appear inline wherever they arrive: message image blocks, images inside tool results, files named by tools, and images attached to prompts with `@path`. None of it enters the buffer as base64. Animated GIFs play and stop automatically. `I` pauses or restarts the image at point, and `RET` opens it. When `ffmpeg` is on `PATH`, a video displays its first frame. `ecc-image-inline` turns off inline images.

### `/resume` in a session

Typing `/resume` in a session continues that window with another recorded conversation from the project. The window, tab, buffer, session name, and review baseline stay in place; only the conversation inside them changes. This matches how `/resume` works in the terminal client.

### The prompt

- `C-c C-r` selects a past prompt from a list and inserts it at point, while `M-p` steps through history one entry at a time.
- The footer now shows the model name before the session responds. It determines the model from the session, the environment, and Claude Code settings files instead of waiting for the first assistant message.

### Breaking

- **The Spaces have the lower-case keys.** `C-c c j` switches to a Space instead of focusing a project. `C-c c b` opens the sidebar and `C-c c B` opens the dashboard -- the two keys have swapped. `C-c c V` resets the tab layout. `C-c c C` no longer creates a worktree (it is now `W c`). In `ecc-menu`, `w` rewrites the region while `W` opens the worktree menu.
- **`ecc-toggle` and `ecc-toggle-all` are gone**, along with `C-c c w`. To restore a session to the screen, use `C-c c V` or switch to the session.
- **`ecc-window-focus-source` is no longer a command**; `ecc-space-reset-windows` has taken over its key and its job.
- **`ecc-prompt-resend-last` is gone**, along with its `C-c C-r`. Pressing `M-p C-c C-c` does what it did.
- **The interrupt is `C-c C-z`**, and `C-c C-g` is unbound. Pressing `C-c` and then `C-g` to cancel the prefix now cancels the prefix, as in every other mode, instead of stopping the turn. `C-c C-k` clears the draft wherever point is; it no longer interrupts from the transcript.
- **One letter, one meaning across buffers.** In the dashboard, `r` resumes and `R` renames, as `C-c c r` and `C-c c R` do. In the transcript, `F` goes to the Files section (was `f`) and `v` goes to the prompt, beside `i`. Capabilities are `C` in the menu (was `y`).
- **`ecc-review` reviews everything that changed since the session started**, instead of only the files the CLI reported editing or writing. Files changed by shell commands or scripts are now included in the review, which is most of what a session does. `ecc-review-untracked-max-bytes` is now `ecc-review-max-bytes`, with the old name kept as an obsolete alias.
- The layout setting is `ecc-use-spaces`, a boolean defaulting to `t`. `ecc-hooks-settings-files`, `ecc-hooks-user-directory`, and `ecc-hooks-managed-files` moved to `ecc-protocol-` names; no settings that users configure have changed names.

This release also includes eleven fixes. Among them are fixes for a session that followed the CLI's cwd out of its own project, a notice injected by the CLI displayed as a user-typed prompt, and `make compile` compiling each file in its own Emacs process -- which caught three files that would not compile on their own. `CHANGELOG.md` has the full record.
