Verified against **Claude Code CLI 2.1.290** and Emacs 30.1.

A small release for the MELPA review. One behaviour changes.

### Keeping the prompt history across restarts

ecc no longer adds `ecc-prompt-history` to `savehist-additional-variables` on
its own. If you use `savehist-mode` and want the prompt history (`M-p` / `M-n`
in the prompt region) kept across restarts, add this to your init:

```elisp
(add-to-list 'savehist-additional-variables 'ecc-prompt-history)
```

Without it, the history saved before the upgrade is read back once more at
the next start, and is dropped at the next save. If you do not use
`savehist-mode`, nothing changes.

### Also

The docstrings of `ecc-plan-mode-map` and `ecc-review-mode-map` no longer write
out key sequences; the review's names its keys as the commands they run, so a
rebinding shows in `C-h m`.

`CHANGELOG.md` has the full record.
