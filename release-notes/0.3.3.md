Verified against **Claude Code CLI 2.1.281** and Emacs 30.1.

Code in the transcript now takes you to the file. One key does something
different: see "Changed" below.

## Open the file at the line

Press `RET` on code in the transcript, or click it, to open the file beside the
session at that line. The line flashes. This works on:

- a line in the diff of an Edit, a MultiEdit, a Write or a NotebookEdit
- a line of a diff in the Files section or in a permission request
- the heading of a tool call that names a file (a Read opens at its offset, a
  change at the first line it changed)
- a path in a reply, such as `foo.el:12` or `x.el#L3`

A NotebookEdit opens the notebook, but not at the line: the lines of a cell
are not lines of the file.

A removed line opens where it used to be. If the session changed the same file
later, the line number follows those changes. Set `ecc-markdown-linkify-paths`
to nil to turn off the links in replies. Redrawing is no slower than before.

## See the change as it is made

A tool call that changes a file now shows its diff open instead of folded
behind `TAB`. The diff looks the way the CLI draws it: each line shows its line
number in the file, and a line at the top of the diff sums it up, for
example "Added 1 line, removed 1 line." File names inside the project are shown
relative to it. Set `ecc-render-inhibit-inline-diff` to fold these calls again.

MultiEdit and NotebookEdit now show a diff too. Before, they showed none, not
even in the permission prompt.

## Typing with an input method

The prompt's placeholder is now hidden while a macOS input method is composing
text, so the text you are composing no longer overlaps it.

## Changed

`RET` on the heading of a tool call that names a file now opens the file. The
`*ecc-detail*` view it used to open has moved to `o`, which works on every node.
On a heading that names no file, such as a Bash call, `RET` still opens
`*ecc-detail*`.

See `CHANGELOG.md` for the full record.
