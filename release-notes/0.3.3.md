Verified against **Claude Code CLI 2.1.281** and Emacs 30.1.

The code in a transcript now leads to the file. One key changes what it does:
see "Changed" below.

## Open the file at the line

`RET` on code in the transcript, or a click on it, opens the file beside the session,
at the line, and flashes it. This works on:

- a line of the diff of an Edit, a MultiEdit, a Write or a NotebookEdit
- a line of a diff in the Files section or in a permission request
- the heading of a tool call that names a file (a Read opens at its offset, a
  change at the first line it changed)
- a path in a reply, such as `foo.el:12` or `x.el#L3`

A removed line opens where it was. Later changes the session made to the same
file move the line number along with them. `ecc-markdown-linkify-paths` turns
the links in replies off. Redrawing costs the same as before.

## See the change as it is made

A tool call that changes a file now comes up with its diff shown instead of
folded behind `TAB`. The diff is drawn the way the CLI draws it: each line has
its line number in the file, and the line over the diff says, for example,
"Added 1 line, removed 1 line." File names inside the project are shown
relative to it. `ecc-render-inhibit-inline-diff` folds these calls again.

MultiEdit and NotebookEdit now show a diff too. Before, they showed none, even
in the permission prompt.

## Typing with an input method

The prompt's placeholder is now hidden while a macOS input method composes
text, so the text being composed is no longer drawn over it.

## Changed

`RET` on the heading of a tool call that names a file now opens the file. The
`*ecc-detail*` view it opened before is now on `o`, which works on every node.
A heading that names no file, such as a Bash call, still opens `*ecc-detail*`
on `RET`.

`CHANGELOG.md` has the full record.
