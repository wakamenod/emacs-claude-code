Verified against **Claude Code CLI 2.1.274** and Emacs 30.1.

A maintenance release: nothing new to learn, three fixes you can see, and the
packaging work that a file of this package should have carried from the start.

### The global modes can be turned on from an init file again

`ecc-notify-mode`, `ecc-tab-line-mode`, `ecc-pending-indicator-mode`,
`ecc-mcp-indicator-mode` and `ecc-track-source-buffer-mode` now carry autoload
cookies. A global mode is exactly the thing turned on from an init file or from
Custom before anything has loaded the file that defines it, and without the
cookie `(ecc-notify-mode 1)` there was a void function, while setting the
variable of the same name set a variable no mode was watching. Starting a
session turned them on either way, which is why this went unnoticed; an Emacs
configured to have them from the beginning now gets them.

### Reviewing in ediff

- **The difference you are standing on is visible.** `ecc-review-ediff-diff-faces`
  gives every other difference the colours of `diff-removed` and `diff-added`,
  and a theme is free to paint the current difference in exactly those colours
  -- modus-vivendi does -- so every difference looked alike and nothing said
  where `n` had just arrived. There are two marks now: the current difference is
  carried five points of lightness away from the frame's background and set in
  bold, and a bar is drawn in the fringe beside every one of its lines, which is
  not a colour to compare. A frame with no fringe at all gets one, in the
  review's own two windows only.
- **Quitting a review gives the cursor back.** On a graphical Emacs the ediff
  control panel is a frame of its own, and taking it down left Emacs with no
  frame the window system considered focused -- which, with
  `cursor-in-non-selected-windows` nil, is no cursor drawn anywhere until
  something was clicked. The review now hands the input focus back to the frame
  it opened in.

### Closing a tab keeps the window

The `x` of a tab stops the session behind it, and a stopped session's window is
deleted so that a row of transcripts is not left holding `*scratch*`. With a tab
line, though, losing one tab is no reason to lose the window: it now moves to the
tab beside the one that closed, passing over a tab another window already shows,
and is deleted only when nothing is left for it to show. With `ecc-tab-line-mode`
off nothing changes.

### Packaging

Every source file now opens with the GPL-3.0-or-later notice that `LICENSE` and
the README already named, an `SPDX-License-Identifier` line, a `Maintainer` and
a `URL`: a file is read on its own often enough -- quoted in a bug report,
vendored into somebody's configuration -- and without a notice in it the terms
are unknowable from the file itself. `Package-Requires` is now written in
`ecc.el` alone, where an installer actually reads it, rather than copied into
forty-two files that were each a chance to name a different Emacs. The
Commentary of `ecc.el` names the commands a session is reached by and says that
the CLI is a separate program.

Nothing here changes a command, a key or a setting. `CHANGELOG.md` has the full
record.
