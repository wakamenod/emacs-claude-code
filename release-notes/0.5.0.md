Verified against **Claude Code CLI 2.1.290** and Emacs 30.1.

Spaces are now the only layout, and the sidebar is the one list of your
sessions: the layout with side windows and the dashboard are gone. Both are
breaking changes; what replaces each is below.

### Every project is a Space

Every project has a Space, a tab of its own, and every session is shown in the
Space of its project. If your init set `ecc-use-spaces` to nil, sessions now
open in a tab per project beside its source, and the sidebar and the Space
commands (`C-c c j`, `C-c c V`, `C-c c z`) work. `ecc-show-session`
(`C-c c v`) goes to the session's tab.

- `ecc-use-spaces` has no effect, and an init that sets it is warned when it
  is compiled.
- If you use the tab bar for other work: starting, answering or resuming a
  session from another tab switches to the session's Space. A review Claude
  opens is still shown without leaving your tab.
- `ecc-window-large-frame-min-height`, `ecc-window-sub-height`,
  `ecc-window-use-side-window`, `ecc-window-side` and `ecc-window-height` are
  obsolete and do nothing. `ecc-window-width` is now only the width of the
  session column of a Space.
- `ecc-focus-project` is removed: `C-c c j` goes to a project's Space, and
  `C-c c V` lays it out again.
- A worktree's repository opened on the way to it comes up as a tab with no
  session in it. Going there starts one, as going to any empty Space does.

### The sidebar replaces the dashboard

`C-c c b` (`ecc-sidebar-focus`) goes into the sidebar, and its keys do what the
dashboard's did: `RET` goes to the session, `c` starts one, `k` stops it, `r`
resumes it (`C-u r` forks it), `R` renames it, and `a` / `d` answer what it
waits on. `r` and `R` are new.

- `ecc-dashboard` is an obsolete alias of `ecc-sidebar-focus`, so a key bound
  to it opens the sidebar. `C-c c B` and `B` in `ecc-menu` are gone.
- The `⚠ecc:N` indicator in the mode line now goes to the next waiting
  request, as `C-c c n` does.
- Not replaced: the dashboard's counts, total cost and rate-limit bar, and its
  model, last prompt, last answer and cost columns. `M-x ecc-usage`
  (`C-c c U`) still shows the rate limits, and `M-x ecc-skill-show` or
  `/skills` the skills.

### Deleting a recording

`ecc-delete-recording`, also `d` in `ecc-resume-menu` (`C-c c ? r d`), deletes
a recorded conversation from `~/.claude/projects`. It always asks which, then
asks again naming the session and the file, and refuses a session that is
running in this Emacs or in another process.

### Fixed

- A Bash call that changed files shows its description and the diff, no
  longer a long one-line command and its output between them.
- `C` in `ecc-menu` (`ecc-capabilities-show`) and `M-x ecc-skill-show` work
  from a session buffer again; they had stopped at "No session on this line"
  anywhere but on a dashboard row.

### If your init customises ecc

- A key added to `ecc-global-map` waits for `ecc`, not `ecc-answer`:

  ```elisp
  (with-eval-after-load 'ecc
    (define-key ecc-global-map "G" #'ecc-review-range))
  ```
- Keys of the permission answers, `C-c C-b`, `C-c C-t`, the review's keys on
  a request, and the files, talk and pull-request keys of a review are bound
  in keymaps of the module that owns them, hung under the chat and review
  maps. A key of your own in those maps still wins.
- `ecc-plan-approve-request` is `ecc-perm-approve-plan-request` and
  `ecc-review-ediff-stacked-p` is `ecc-review-talk-stacked-p`; the old names
  are obsolete aliases. The git helpers of `ecc-worktree.el` and
  `ecc-review.el` moved to `ecc-git.el` as `ecc-git-*`, without aliases.
- When another package's `project-find-functions` signals while ecc names a
  session's project, the error is shown once per directory instead of being
  dropped.

### How it is put together

Forward declarations went from 90 to 41, and those naming a module of ecc
from 53 to 4: two pairs, each kept on purpose. New low modules,
`ecc-git.el` and `ecc-display.el`, hold what git is asked and how a session is
shown, and the Capabilities buffer is in `ecc-capabilities.el`. Loading the
chat mode loads 14 modules where it loaded 25.

`CHANGELOG.md` has the full record.
