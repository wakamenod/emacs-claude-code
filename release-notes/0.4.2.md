Verified against **Claude Code CLI 2.1.290** and Emacs 30.1.

This release has two breaking changes, both in the window layout of a Space;
they are listed at the end.

### Cost is counted right

Every release before this one showed the wrong cost. The CLI reports the
running total of the process with each result, and ecc added that total to the
session's total on every turn: three turns of $0.01 came to $0.06. A turn's
cost line now shows what that turn added, and the session's total -- the
dashboard's Cost column and `%c` in `ecc-mode-line-format` -- is what the CLI
says the conversation cost. A resumed or forked session carries on from the
total in its recording.

### Restarting a session

`ecc-restart` stops the CLI of an idle session and starts it again on the same
conversation, in the same buffer. The transcript, the draft, the review
baseline and the permission mode stay. Use it for a CLI that stopped answering,
or to make it read changed settings, MCP servers or plugins. `R` in a session
buffer restarts a running session and resumes a stopped one; `ecc-menu` has it
under `S`. A session in the middle of a turn, or with prompts queued, is
refused.

### The queue

- The prompts waiting for the running turn are drawn at the end of the
  transcript under `⏸ Queued (N)`.
- `C-c C-q` opens a list of them. `RET` takes a prompt back into the prompt
  region, `d` drops one, and `M-<up>` / `M-<down>` move it.
- A queued prompt is no longer lost when the session is handed to the terminal
  or carried on with `/resume` mid-turn.

### Replies

- `RET` on a path Claude wrote opens the file even when the path is only a
  name, or relative to another directory: it is looked up in the files the
  session touched, the project and the buffers Emacs visits. Several matches
  are offered to choose from. As a last resort the whole machine is searched
  (Spotlight or `locate`), after asking; `ecc-visit-search-machine` sets that.
- A ` ```mermaid ` block is shown as its diagram when `mmdc` (mermaid-cli) is
  on `exec-path`. It is drawn in the background, the source stays underneath,
  and `I` toggles between the two.
- Numbered list items show their numbers instead of a bullet.
- A long Bash command no longer pushes the diff of what it changed out of
  view: a tool's input is cut to `ecc-render-result-max-lines`, like its
  output, and `RET` shows all of it.
- Slash commands the CLI runs itself (`/rename`, `/model`, `/cost`) are drawn
  as commands, not as replies.

### Renaming

`/rename` and `C-c c R` now keep the name: it reaches the CLI, the recording,
every tab line and `ecc-restore`, and a session opened again from the history
comes back under it.

### Spaces

- `C-c c V` cycles six layouts: source and one session, two sessions side by
  side, source and two sessions in thirds, two sessions over the source,
  source and two sessions stacked, and a grid of four. A layout the frame has
  no room for is skipped. Under `repeat-mode`, `C-c c V V V` cycles.
- A new session in a Space takes the window of the session used longest ago
  rather than dividing the screen again.
- The picker of `C-c c j` groups the Spaces into `Open` and `Past` and draws
  each line as the sidebar draws it.
- `C-c c z` no longer deletes the sidebar on the second zoom.

### Breaking

- **`C-c c V` is `ecc-space-cycle-layout`.** It used to rebuild the windows
  of the Space once; pressed once after anything else it still builds the
  layout the tab last used. `ecc-space-reset-windows` remains as an obsolete
  alias.
- **`ecc-space-session-min-width` does nothing.** How many sessions a Space
  shows is decided by the layout.

This release also has fixes to the review, to hand-offs to the terminal and to
paren highlighting in session buffers; `CHANGELOG.md` has the full record.
