Verified against **Claude Code CLI 2.1.280** and Emacs 30.1.

A maintenance release with seven fixes. Nothing changes a command, a key, or a
setting.

Most of it fixes one bug. If a repeating timer's tick takes longer than its
interval, Emacs locks up -- no key, no `C-g`, no emacsclient. In an Emacs that
had been running for a day, the sidebar's spinner was taking 0.39 s a tick on a
0.2 s timer. Every repeating timer in the package now goes through
`ecc-visual-repeat`, which turns an effect off when it cannot keep up. Spinners
now turn in place with undo off instead of redrawing every row. Drawing the
transcript also takes much less work: `scripts/bench-render.el` reports
0.1--0.2 ms a redraw of the live region, down from 0.2--0.6 ms.

The rest:

- A Space with more sessions than its row can hold no longer opens with crushed
  transcripts, and a session window no longer takes its width from the sidebar.
- The transcript now displays any picture or video written by a Bash command.

`CHANGELOG.md` has the full record.
